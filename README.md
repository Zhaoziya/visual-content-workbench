# RedNote · 图文笔记工作台

纯前端应用：React、TypeScript、Vite。Markdown 使用 Marked 和 DOMPurify；正文编辑采用 CodeMirror；PNG 使用 html-to-image；ZIP 使用 JSZip；本地草稿存储在 IndexedDB。

## 启动

```sh
npm install
npm run dev
```

默认在本机打开，不需要后端。生产静态文件通过 `npm run build` 生成到 `dist/`。

## 当前功能

- 标题、副标题和 Markdown 正文分开编辑。
- 标题与副标题使用普通输入框；正文可在 Markdown 源码与 Tiptap 富文本编辑之间切换。富文本修改、格式调整、图片插入和手动分页同步回 Markdown，并更新右侧笔记预览。
- 工具栏包含一、二、三级标题，以及在光标位置插入并立即应用的手动分页图标；源码 / 预览切换图标位于同一工具栏末尾。
- 解析标题、粗体、斜体、有序与无序列表、引用、代码块、表格和图片。
- 模板库按模板与主题组织：经典图文包含海蓝、配色文档中的八组主题，以及复古时光胶卷、复古胶片时光、北欧深邃峡湾三组参考图主题，也可手动上传背景。
- 内置主题使用固定配色，上传背景匹配一套配色，七个颜色均可编辑。
- 自动分页、可调正文大小与内容间距、背景遮罩、连续预览和缩放。
- IndexedDB 自动保存，下载 / 导入包含图片资源的 JSON 草稿。
- 导出单页 PNG，或将全部 PNG 打包为 ZIP。尺寸为 1242 × 1660。
- 上传正文图片后自动插入 Markdown。图片保留在草稿中。

## Markdown 约定

一级标题是章节，二级标题是小标题；正文中不会自动改写标题。
独占一行的 `---` 或 `<!-- pagebreak -->` 表示手动分页。
使用引用 `> 说明` 表示补充说明，不带黄色标题竖线。
同一段中的两张图片会并排展示，例如：

```md
![第一张图](图片-1.png) ![第二张图](图片-2.png)
```

提示词区域使用如下语法：

````md
```prompt 布局规则
同类组件之间采用统一间距。
新增组件与相邻组件的边缘对齐。
```
````

普通代码块仍按代码展示。导入 Markdown 时，文件第一行的 `# 标题` 会填入左侧标题模块。

## 本地数据与图片

草稿自动存储在当前浏览器、当前站点的 IndexedDB 中。“保存草稿”还会下载 JSON 文件，可用于备份或迁移到另一台电脑。
更换端口或清理浏览器存储会影响本地草稿访问；重新导入下载的草稿可恢复。
不同网址的草稿不会自动同步；迁移时请导出并导入草稿。
应用不上传内容。远程图片本身仍会产生访问其所在网站的请求；受跨域限制的图片可能无法提色或导出，建议使用上传入口。
图片超过页面容量或无法加载时会给出提示，不导出静默裁切的错误图片。

## 设计与验证

本地开发资料未随公开仓库发布。修改界面后应检查桌面和窄屏布局，并试用编辑、预览与导出流程。
